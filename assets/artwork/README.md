# Original portfolio artwork

Seven final illustrations generated with OpenAI's built-in image generation tool for Jan Sultan's portfolio. No external stock assets, third-party models, copied logos, or referenced project screenshots are included. There is no third-party asset licence to attribute. These illustrations represent subject areas, not certifications, deployments, or project evidence.

The transparent PNG masters are stored here. Responsive transparent WebP files and the machine-readable manifest are in `public/art/`. That manifest records every filename, exact byte size, dimensions, source, and final/placeholder status. The project screenshot slots on the page remain explicitly marked pending.

## Prompt set

The first prompt established a substantial original faceted security shield in three-quarter view: a brushed graphite titanium rim, thick translucent cobalt-blue glass, amber circuit pathways and a small amber keyhole. Polished product-render quality, upper-right blue rim light and upper-left warm amber key light, physically convincing bevels and glass thickness, no text, logos, checkmark, computer window, stock artwork, or unrelated objects; genuine transparent alpha outside the object.

Each subsequent prompt used the shield as a material and lighting reference, with the instruction to create a new icon, preserve the same graphite/cobalt/amber/ivory palette and studio quality, show the whole object with transparent margins, and not repeat the shield or include text, logos, ground planes, pink, or purple:

- `padlock-key`: rounded-square metal security padlock, curved shackle, thick blue-glass face, amber keyhole, and one sculptural metal key beside its lower edge.
- `network-globe`: polished blue-glass globe in a graphite meridian cage, connected spherical network nodes and thin amber links; a readable globe silhouette rather than a random molecule.
- `code-laptop`: open graphite laptop, blue-glass screen, bevelled keyboard deck, a few abstract amber and ivory code-like line marks; no legible text or invented application UI.
- `ctf-flag`: subtly rippling blue-glass pennant on a graphite pole and bevelled base, thin amber edge stripe; no writing, logos, trophy, or credential claims.
- `ai-chip`: graphite processor, polished contact pins, translucent blue-glass core with an embedded amber neural circuit pattern; no letters or logos.
- `glass-cube`: one transparent smoked-cobalt glass cube in isometric view with three visible faces, rounded bevels, optical refraction, cool blue edge reflections and a restrained amber reflection. No metal cage or symbols. This is a supporting depth element.

## Export

Alpha bounds were normalized onto square transparent canvases with approximately 9% margins. The shield has a 1280 px PNG master and 640/960/1280 px WebP variants; other assets have 1024 px PNG masters and 160/320/640 px WebP variants. WebP quality is 82 for the hero and 80 for other images. PNG masters use lossless optimization. No realtime hero engine is needed.

The 1200 x 630 social preview at `public/og-image.png` uses the same shield and self-hosted typography. Its actual dimensions and byte size are recorded separately in the artwork manifest.
